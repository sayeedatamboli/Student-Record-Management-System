# Student Record Management System

## Project Overview
The Student Record Management System is a Data Structures and Algorithms (DSA) micro project developed to demonstrate the management of student information using programming concepts and data structures.

The project aims to simplify student record management by providing operations for maintaining and accessing student details.

## Objectives
- To understand and apply Data Structures and Algorithms.
- To manage student information efficiently.
- To implement searching, updating, and deleting operations.
- To understand the use of graphical interfaces in programming.

## Features
- Add student records.
- Display student records.
- Search for student records.
- Update existing student information.
- Delete student records.
- Graphical interface using `graphics.h`, if supported by the uploaded implementation.
